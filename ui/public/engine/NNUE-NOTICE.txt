Stockfish NNUE Evaluation Networks — Attribution & License
==========================================================

The in-browser engine BlundrIQ ships (Stockfish 19 Lite, single-threaded
WebAssembly, stockfish-19-lite-single.wasm) embeds an efficiently-updatable
neural network (NNUE) for position evaluation.

This is the LITE flavor. The nmrugg/stockfish.js wrapper (tag v19.0.0) names
both networks in its src/evaluate.h:

    EvalFileDefaultName = "nn-1a298aa575a0.nnue"   (standard build)
    EvalFileLiteName    = "nn-61e7af4bb97d.nnue"   (Lite build)

and a Lite build aliases the default name to the Lite one (USE_LITE_NET). So
the single network embedded in the shipped binary is:

    nn-61e7af4bb97d.nnue
    1,166,381 bytes
    SHA-256 61e7af4bb97d51eeeb25d322916f86513b5cd3a827ce189c98c6e31946f99e5b

The standard build's nn-1a298aa575a0.nnue is NOT embedded by this binary.

The Stockfish 19 lite networks were produced by Chris Bao (sscg13) on the
sscg13/Stockfish branch sf19-1mb, as the wrapper's README credits; the feature
set they need is part of the wrapper's engine source, which is what was
compiled.

The NNUE networks are part of Stockfish and are distributed under the GNU
General Public License v3 (the same license as the engine) — they carry no
separate or additional licensing obligation beyond GPLv3. The network identity
is fixed by the SHA hash embedded in each filename above (the file name is the
first 12 hex characters of the network's SHA-256).

The complete corresponding source for the shipped binary — including the
Stockfish 19 source, the nmrugg/stockfish.js wrapper whose src/ is the engine
source the build compiles, and the Emscripten build configuration — is provided
in stockfish-source.tar.gz alongside this notice, and is linked from the
BlundrIQ Explore view's footer. The embedded network file itself,
nn-61e7af4bb97d.nnue, is physically included in that archive under networks/ —
not merely referenced by name — so the corresponding source is complete without
any network download.
