# blundriq

A personal chess improvement tool: it imports my games from Chess.com and Lichess, runs Stockfish over them, and shows me my recurring blunders, where I leave my opening repertoire, puzzles cut from my own mistakes (with spaced repetition), opponent scouting, and a game review.

Single user, deliberately small. `CLAUDE.md` is the rulebook, `ARCHITECTURE.md` the map. Built by me with Claude as the developer and Codex as the reviewer, as a rebuild of an earlier multi-user version.

Stockfish is GPL-3.0; its notices will ship with the in-browser engine under `ui/public/engine/` when Explore lands.
